# 有效复制现有项目 — 共享

此视频介绍如何复制项目而不是使用模板。 要&#x200B;复制项目，请打开所需的项目，单击项目名称旁边的三个圆点菜单，然后选择“复制”。 在“复制项目”窗口&#x200B;中，您可以重命名项目并更改其状态（通常为“计划”），以避免向分配的用户发送通知。 您&#x200B;可以选择是否复制分配、进度、自定义数据等&#x200B;。
要完成，请单击“复制项目”。 &#x200B;
在此过程中不能直接复制问题，因为它们不被视为计划工作。 要&#x200B;复制问题，请转到问题选项卡，选择所需的问题，并使用“复制到”选项将它们转移到新项目。 &#x200B;


>[!VIDEO](https://video.tv.adobe.com/v/3456048/?captions=chi_hans&quality=12&learn=on&enablevpops=1)

## 关键要点

* **复制项目：**&#x200B;打开项目，单击项目名称旁边的三个点菜单，然后选择“复制”以复制项目。 &#x200B;
* **调整项目设置：**&#x200B;重命名项目并将其状态更改为“计划”，以避免向已分配的用户发送通知。
* **选择性复制：**&#x200B;您可以选择复制分配、进度或自定义数据。 取消&#x200B;选择这些选项允许在新项目中自定义。
* **处理自定义数据：**&#x200B;如果取消选择自定义数据，则复制表单时将不包含其数据。 保&#x200B;留选中此框可复制表单及其数据。 &#x200B;
* **单独复制问题：**&#x200B;项目复制过程中不会复制问题。 要&#x200B;复制这些问题，请转到问题选项卡，选择所需的问题，然后使用“复制到”选项将它们转移到新项目。 &#x200B;
