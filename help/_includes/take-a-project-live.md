# 让项目上线 — 共享

此视频介绍将项目状态更改为“当前”以使其上线的最后步骤。 在执行&#x200B;此操作之前，它强调审查关键项目元素，包括任务名称、持续时间、计划小时数、前置任务、开始日期和完成日期以及任务，以确保一切准确且正确设置。 项目上线&#x200B;后，项目经理将收到基于全局设置和个人设置的通知，并且项目将显示在活动项目的报告和过滤器中。 这&#x200B;标志着这项工作的正式开始。 &#x200B;

>[!VIDEO](https://video.tv.adobe.com/v/3439002/?captions=chi_hans&quality=12&learn=on&enablevpops=1)

## 关键要点

* **审查项目详细信息：**&#x200B;确保任务名称、持续时间、计划的小时数、前置任务、开始和完成日期以及分配准确且设置正确。 &#x200B;
* **更改项目状态：**&#x200B;在项目标题或详细信息中将项目状态更新为“当前”以使其生效。 &#x200B;
* **接收通知：**&#x200B;作为项目经理，一旦项目上线，您将开始根据全局设置和个人设置接收通知。 &#x200B;
* **跟踪活动项目：**&#x200B;该项目将显示在实时、当前或正在进行的项目的报告和筛选器中，从而更易于监视。 &#x200B;
* **开始工作：**&#x200B;项目正式上线开始工作和执行阶段。 &#x200B;
