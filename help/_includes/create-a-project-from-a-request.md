# 将问题或请求转化为项目 — 已共享

该视频演示了如何将问题或请求转化为项目。

>[!VIDEO](https://video.tv.adobe.com/v/340343/?quality=12&learn=on&enablevpops=1)

## 关键要点

* **转换流程：**&#x200B;要将问题或请求转换为项目，请选择问题，使用三个点菜单，然后选择转换选项，最好使用模板。 &#x200B;
* **模板选择：**&#x200B;为保持一致性和简便性，建议使用模板。 您&#x200B;可以根据项目要求查看和选择相应的模板。 &#x200B;
* **项目详细信息：**&#x200B;默认情况下，项目名称和描述是从问题中复制的，但可以编辑。 问题中的&#x200B;自定义表单也会转移到项目中。 &#x200B;
* **问题解决方案：**&#x200B;您可以选择将原始问题与项目绑定，防止在项目完成前将其标记为已解决。 或者，&#x200B;可以在转换时删除问题。 &#x200B;
* **访问和可见性：**&#x200B;您可以向请求者授予对项目的访问权限。 已转换的项目&#x200B;将显示在“已转换为”列中，指示它是否已转换为任务或项目。 &#x200B;
