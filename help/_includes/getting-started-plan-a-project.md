# 在Workfront中有效计划项目 — 共享

此视频提供了有关如何在Workfront中有效规划项目的指导。 它强调了&#x200B;为项目打下坚实基础的重要性，以确保项目按时完成并取得成功。 关&#x200B;键步骤包括了解五个关键字段：任务、分配、持续时间、已计划小时数和前置任务。 利用&#x200B;这些字段，可以快速准确地调整项目计划。 &#x200B;

该视频强调了切合实际的时间表、团队可用性和准确规划的重要性，从而为项目成功奠定坚实的基础。 &#x200B;

>[!VIDEO](https://video.tv.adobe.com/v/3448577/?captions=chi_hans&quality=12&learn=on&enablevpops=1)

## 关键要点

* **关注五个关键字段：**&#x200B;了解任务、分配、持续时间、计划小时数和前置任务，以便对项目计划进行高效、准确的更改。 &#x200B;
* **将项目状态设置为“计划”：**&#x200B;确保项目状态设置为“计划”，以防止在调整计划时收到不必要的通知。 &#x200B;
* **使用相应的视图：**&#x200B;利用标准视图或自定义视图来关注基本项目详细信息，如任务、持续时间和分配。 &#x200B;
* **选择切合实际的开始日期：**&#x200B;设置切合团队可用性的实际开始日期，并避免出现不切实际的情形，如假日或周末。 &#x200B;
* **利用计划模式：**&#x200B;使用“开始日期”模式计算完成日期，或使用“完成日期”模式计算开始日期，确保时间表与项目要求一致。 &#x200B;
